커널 융합

컬러 사진의 밝기를 낮춘 다음 흑백으로 바꾼다. 따로 실행하던 이 두 연산을 하나의 GPU 커널에서 처리하는 것이 커널 융합이다.

GPU 커널의 예

CUDA에서는 GPU에서 병렬로 실행하도록 호출하는 함수를 커널(kernel)이라고 한다. 예를 들어 사진의 밝기를 낮추는 커널은 여러 픽셀에서 동시에 빨강·초록·파랑 값을 줄인다.

CUDA 이전인 2004년에도 Brook 연구진은 여러 데이터에 같은 계산을 적용하는 함수를 커널이라고 불렀다.

CUDA 가이드Brook 발표 자료

두 커널로 나누어 실행할 때

첫 번째 커널은 각 픽셀의 밝기를 원래의 65%로 낮춘다. 두 번째 커널은 어두워진 컬러 사진을 흑백으로 바꾼다.

한 커널로 합쳐서 실행할 때

한 커널 안에서 각 픽셀의 밝기를 65%로 낮추고, 그 값으로 흑백 밝기를 계산한다.

두 방식 모두 밝기 조절을 먼저 한다. 따로 실행하면 커널 호출은 두 번, 합치면 한 번이다.

GPU 메모리 접근 비교

그림의 왼쪽은 데이터를 저장하는 GPU 메모리(VRAM), 오른쪽은 계산을 수행하는 연산 장치(COMPUTE)다.

위 · 개별 실행
첫 커널이 어두워진 컬러 사진을 메모리에 저장한다. 흑백 변환 커널이 이 사진을 다시 읽는다.
아래 · 융합 실행
밝기를 낮춘 픽셀 값을 같은 커널에서 바로 사용한다. 중간 컬러 사진을 저장할 필요가 없다.

언어 모델 추론에서 쓰는 이유

신경망에는 행렬곱을 한 뒤 정해진 값(편향)을 더하는 층이 있다. 두 연산을 합치면 행렬곱 결과를 별도 배열에 저장할 필요가 없다.

행렬곱 결과가 1 MB일 때의 계산 예. 중간 배열을 쓰고 읽는 양만 비교한다.

융합이 불리한 경우

계산 중에 보관할 값이 많을 때

GPU에는 계산 중인 값을 잠시 보관하는 공간인 레지스터가 있다. 각 작업이 더 많은 레지스터를 쓰면 동시에 실행할 수 있는 작업 수가 줄어 오히려 느려질 수 있다.

다른 연산에도 중간값이 필요할 때

예를 들어 다른 층에서도 편향을 더하기 전의 행렬곱 결과를 사용한다면, 그 결과를 따로 저장하거나 다시 계산해야 한다.

성능을 확인할 때는 같은 모델에 같은 입력을 주고, 융합 전후에 토큰 하나를 생성하는 데 걸린 시간을 비교한다.
